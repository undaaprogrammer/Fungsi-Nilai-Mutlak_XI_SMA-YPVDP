01
INTRODUCTION

Mengenal Grafik Fungsi Nilai Mutlak

Fungsi nilai mutlak merupakan fungsi yang menghasilkan nilai tidak negatif. Grafiknya memiliki bentuk khas menyerupai huruf V, dengan titik puncak sebagai titik perubahan arah grafik.

Bentuk umum fungsi nilai mutlak yang kita pelajari adalah:

f(x) = |ax + b|
The general form of absolute value function

Keterangan:

a = koefisien x yang memengaruhi kemiringan grafik.
b = konstanta yang memengaruhi posisi titik puncak.

Sebagai contoh, fungsi f(x) = |x − 2| memiliki titik puncak pada koordinat (2, 0).

Karakteristik Grafik

• Berbentuk huruf V.
• Turun terlebih dahulu, kemudian naik.
• Nilai fungsi tidak pernah negatif.
• Memiliki titik puncak (vertex).
• Domain berupa seluruh bilangan real.
• Range berupa y ≥ 0.

05
PARAMETER ANALYSIS

Bagaimana Parameter Memengaruhi Grafik?

Setelah melakukan eksperimen, mari pahami pengaruh parameter a dan b terhadap grafik fungsi nilai mutlak.

a

Pengaruh Koefisien a

Nilai a memengaruhi tingkat kemiringan atau kecuraman grafik. Semakin besar nilai mutlak a, semakin sempit grafik. Sebaliknya, semakin kecil nilai mutlak a, semakin lebar grafik.

Jika a negatif, grafik tetap berbentuk V karena seluruh ekspresi berada di dalam tanda nilai mutlak.

b

Pengaruh Konstanta b

Nilai b memengaruhi posisi titik puncak grafik pada sumbu x.

Posisi titik puncak dapat ditentukan menggunakan rumus x = −b/a, selama a tidak sama dengan nol.

V

Bentuk dan Sifat Grafik

Grafik berbentuk huruf V, turun terlebih dahulu kemudian naik.

Nilai fungsi tidak pernah negatif. Domain adalah seluruh bilangan real dan range adalah y ≥ 0.

✳ Let's Remember!

Bentuk umum fungsi nilai mutlak adalah f(x) = |ax + b|.

Parameter a memengaruhi kemiringan grafik, sedangkan b memengaruhi posisi titik puncak.

Untuk a tidak sama dengan nol, titik puncak berada pada koordinat (−b/a, 0). Grafik selalu menghasilkan nilai yang tidak negatif.
