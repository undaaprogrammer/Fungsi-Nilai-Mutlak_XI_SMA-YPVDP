01
INTRODUCTION

Mengenal Grafik Fungsi Nilai Mutlak

Grafik fungsi nilai mutlak memiliki bentuk khas menyerupai huruf V. Bentuk dan posisinya dapat berubah bergantung pada parameter yang terdapat dalam persamaan.

Untuk memahami perubahan tersebut, kita akan menggunakan bentuk umum fungsi nilai mutlak berikut:

f(x) = a|x − h| + k
The general form of absolute value function

Pada fungsi tersebut, a, h, dan k merupakan parameter yang menentukan karakteristik grafik. Dengan mengubah nilai ketiganya, kita dapat mengamati perubahan bentuk dan posisi grafik.

05
PARAMETER ANALYSIS

Bagaimana Parameter Memengaruhi Grafik?

Setelah mencoba berbagai skenario, mari pahami alasan di balik perubahan grafik. Setiap parameter mempunyai pengaruh yang berbeda terhadap bentuk dan posisi grafik.

a

Pengaruh terhadap Bentuk Grafik

Jika a positif, grafik membuka ke atas. Jika a negatif, grafik membuka ke bawah. Semakin besar nilai mutlak a, semakin sempit grafik. Sebaliknya, jika 0 < |a| < 1, grafik semakin lebar.

h

Pergeseran Horizontal

Jika h positif, grafik bergeser ke kanan. Jika h negatif, grafik bergeser ke kiri. Pergeseran ini mengubah posisi titik puncak secara horizontal.

k

Pergeseran Vertikal

Jika k positif, grafik bergeser ke atas. Jika k negatif, grafik bergeser ke bawah. Pergeseran ini mengubah posisi titik puncak secara vertikal.

✳ Let's Remember!

Bentuk umum fungsi nilai mutlak f(x) = a|x − h| + k menunjukkan bahwa perubahan parameter a, h, dan k memengaruhi karakteristik grafik.

Parameter a menentukan arah buka dan tingkat kecuraman grafik, sedangkan h dan k mengatur posisi titik puncak secara horizontal dan vertikal.
