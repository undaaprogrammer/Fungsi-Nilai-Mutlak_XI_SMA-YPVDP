01

Apa Itu Nilai Mutlak?

Sebelum mencoba berbagai aktivitas, mari pahami satu konsep utama: nilai mutlak merupakan jarak suatu bilangan terhadap nol pada garis bilangan, tanpa memperhatikan arah.

The Distance Concept

Coba geser slider di bawah. Perhatikan bagaimana posisi bilangan berubah dan berapa jaraknya dari nol.

INTERACTIVE NUMBER LINE
Choose your number -7
Selected Number (x) -7
Absolute Value |x| 7
Jarak dari -7 menuju nol adalah 7 satuan.

What can you conclude?

Perhatikan bahwa -7 dan 7 memiliki nilai mutlak yang sama, yaitu 7. Keduanya berada pada jarak yang sama dari nol, tetapi pada arah berlawanan. Nilai mutlak selalu bernilai positif atau nol.

02

Bentuk Umum Nilai Mutlak

Nilai mutlak memiliki aturan berdasarkan tanda bilangan di dalamnya. Jika bilangan tidak negatif, nilainya tetap. Jika negatif, tandanya berubah menjadi positif.

THE GENERAL DEFINITION
|x| =
WHEN x ≥ 0
|x| = x

Jika x positif atau nol, nilai mutlaknya sama dengan bilangan tersebut.

WHEN x < 0
|x| = -x

Jika x negatif, nilai mutlaknya adalah lawan dari bilangan tersebut.

ABSOLUTE VALUE CALCULATOR

Calculate it yourself!

Masukkan bilangan apa saja. Sistem akan menentukan aturan yang digunakan dan menampilkan prosesnya.

CALCULATION RESULT
|-8| = 8

Karena -8 negatif, gunakan aturan |x| = -x. Jadi |-8| = -(-8) = 8.

03

Domain dan Range

Dalam suatu fungsi, kita mengenal dua istilah penting: domain sebagai himpunan nilai masukan dan range sebagai himpunan nilai keluaran.

DOMAIN · INPUT

Daerah Asal

D = ℝ

Semua bilangan real dapat dimasukkan ke dalam fungsi nilai mutlak, termasuk bilangan negatif, nol, dan positif.

RANGE · OUTPUT

Daerah Hasil

R = y ≥ 0

Hasil fungsi nilai mutlak selalu nol atau lebih besar dari nol.

INPUT - OUTPUT EXPLORER

05

Miskonsepsi Nilai Mutlak

Apakah semua pernyataan berikut benar? Pilih TRUE atau FALSE dan lihat pembahasannya.

STATEMENT 01
|-8| = -8 karena bilangan di dalam tanda mutlak adalah negatif.
Jawaban: FALSE.
|-8| = 8 karena nilai mutlak menyatakan jarak dari nol dan jarak tidak mungkin negatif.
STATEMENT 02
Domain fungsi f(x) = |x| adalah seluruh bilangan real.
Jawaban: TRUE.
Semua bilangan real dapat dimasukkan ke dalam fungsi nilai mutlak.
STATEMENT 03
Grafik fungsi f(x) = |x| memiliki range seluruh bilangan real.
Jawaban: FALSE.
Range fungsi dasar adalah y ≥ 0, karena hasil nilai mutlak tidak negatif.
